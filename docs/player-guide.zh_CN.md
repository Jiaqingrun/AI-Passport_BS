# 余烬存档管家 · 玩家操作指南

## 你需要准备

- AI Passport 一台，Type-C **数据线**（不能是纯充电线）
- 电脑：Windows / macOS / Linux
- 浏览器：**桌面版 Chrome 或 Edge**（不支持手机浏览器、不支持 Firefox/Safari 的 Web Serial）
- Python 3.8+（仅本地启动小服务时需要；不用安装额外库）

## 第一次使用

1. 打开本仓库的存档管家页面，或运行：
   ```bash
   python3 tools/save-manager/server.py
   ```
2. 若地址栏不是 `localhost` / `https`，先点页面上的 **下载本地存档工具 ZIP**，解压后在本机启动。
3. **01 选择保存目录** → 选一个你找得到的私人文件夹。
4. 设备开机，插上电脑 → **02 连接设备** → 弹窗选 `USB JTAG/serial`。
5. 设备进入 **设置 → 备份存档 → 确认**。
6. 本页进度走到 100%，文件列表出现 `Ember-….emsave` 且写着「校验通过 · 已落盘」→ 成功。

## 导入（换固件 / 完整包清档后）

1. 确认手里有当初那份 `.emsave`，并且是**这台**设备备份的。
2. 先在设备打开 **设置 → 导入存档**。
3. 本页选文件；确认「校验通过」后点 **发送导入请求**。
4. 设备上把焦点从默认的「取消」改到「确认覆盖」，再按确认键。
5. 本页会先额外存一份 `Ember-before-import-…`，再传送。
6. 设备重启后，**重新连接**本页，直到看到「存档导入完成」。
7. 在游戏里看：天数、仓库、线索是否还在。

## 常见问题

**一直停在「等待设备响应」**  
固件可能尚未接入 `!EMBACKUP`。请更新到带「备份存档」菜单的《余烬》版本，并关闭其它串口工具。

**提示备份不属于此设备**  
`.emsave` 绑死 `device_id`。不能把 A 机备份导入 B 机。

**完整安装后进度没了**  
社区完整包常擦 NVS。用安装前的备份走导入流程。

**「校验通过」但游戏还是旧进度 / 空档**  
校验通过 ≠ 导入完成。必须看到导入完成回执，并在设备上肉眼确认。

**误点了「结束本次结果核对」**  
只是关掉网页的待核对状态，不是撤销导入。以设备上实际进度为准，并留好原备份。

## 刷机口诀

> 先备份，再刷机；完整包装完再导入；保档刷机也不妨多留一份。
