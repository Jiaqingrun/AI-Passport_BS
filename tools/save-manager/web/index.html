EMBER / AI PASSPORT

余烬 · 存档管家

把据点进度安全地留在这台电脑上。更新社区包、换机、误刷机之前，先做一次备份。

从下载入口开始

浏览器只允许在 HTTPS 或 localhost 使用 USB。若你是从普通 HTTP 链接打开本页，请先下载本地工具：

下载本地存档工具 ZIP （Python 3.8+，无需 pip）

  1. 解压 ZIP，在解压后的文件夹打开终端。
  2. macOS / Linux：python3 server.py；Windows：py -3 server.py。
  3. 用桌面 Chrome / Edge 打开 http://localhost:8765/，保持终端运行。

端口被占用时追加 --port 8766，并打开对应 localhost 端口。文件只保存在你的电脑，不会上传。

尚未选择

提示：目录授权只对当前浏览器会话有效；断线后若提示失效，重新点一次本按钮即可。

02　连接设备

未就绪

用支持数据的 Type-C 线连接 AI Passport，设备开机。在弹窗中选择名称含 USB JTAG/serial 的接口。

尚未连接
  • 先关闭串口监视器、刷写工具、其它占用同一口的程序
  • 不要选蓝牙耳机等无关设备
  • 连接本身不会自动导出存档，必须在设备上确认备份

03　在设备上备份

未就绪

设备路径：设置 → 备份存档 → 确认（具体文案以固件菜单为准）。确认后本页开始接收并校验。

请先完成目录与连接。

    看到「校验通过 · 已落盘」才算备份成功。设备若提示「未检测到电脑」，请确认本页仍显示已连接。

    04　导入已有存档

    未就绪

    顺序很重要：先在设备打开「设置 → 导入存档」，再在本页选文件并发送。设备默认选中取消；确认覆盖后会先把当前档备份到上面选的目录。

    尚未选择文件
    • 仅限同一台 AI Passport（设备 ID 必须一致）
    • 确认覆盖后保持供电；完成时设备会重启
    • USB 断开后请重新连接本页，看到「导入完成」才算成功
    • 「校验通过」只说明文件完整，不等于已经导入

    更新游戏 / 刷社区包之前

    1. 用本工具备份，确认列表里出现新的 .emsave。
    2. 把文件复制到第二个位置（网盘私人目录或另一块盘）。
    3. 再安装社区完整包。完整安装常会清空 NVS，即使游戏名相同。
    4. 安装后回到本页导入；只有标注「保留存档更新」的工具才会跳过存档区。

    保档刷机（只写应用分区）与「完整安装」不同。不确定时，先备份再动手。

    这份备份里有什么

    包含《余烬》写入 NVS 的持久进度：天数与墙钟、仓库与资源、远征与站事、线索与电台相关持久状态、已保存的亮度/声音等设置。未落盘的临时界面光标、一次性动画不在恢复范围内。

    备份含设备 NVS 原始数据，可能夹带其它命名空间信息。请放在私人目录，不要提交到 Git，不要公开分享。

    设计参考了社区开源项目 PokeWalk 存档管理 （USB Web Serial + 本机落盘、导入前自动预备份）。本仓库协议为 !EMBACKUP / .emsave，与 .pksave 不互通。

    固件需实现 USB 存档协议后，本页的备份/导入才会响应。接入说明见仓库 docs/firmware-integration.zh_CN.md。
